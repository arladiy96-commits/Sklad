# Склад

Android-приложение для кладовщика: сканируем одинаковые бумажные расходные накладные, находим код товара и количество, проверяем строки и получаем суммарную ведомость для грузчиков.

## Начальная номенклатура

В `assets/catalog/products.json` заведены **7 разных позиций** по двум присланным фото накладных. Остальные позиции (~20 всего) предстоит добавить через редактор справочника в приложении. Поле `confirmedByWarehouse: false` означает, что код и фасовку ещё следует сверить с оригиналом/складом.

Каждая запись: `code` (код с нормализованной латинской H), `name`, `bagWeightKg`, `active`, `confirmedByWarehouse`. Первую букву `Н` (кириллица) при распознавании приравниваем к `H` (латиница). Нельзя слепо заменять остальные неоднозначные OCR-символы.

## Механика

1. Фото накладной, выравнивание листа и таблицы.
2. Чтение **кода товара, количества кг, цены, суммы** и номера накладной локальным OCR, без облака.
3. Сопоставление распознанного кода со справочником. Неизвестный или неоднозначный код — на проверку.
4. Расчёт мешков: `количествоКг / bagWeightKg`. Некратное фасовке количество требует проверки.
5. Дополнительная арифметическая проверка: `количествоКг × цена = сумма` с учётом округления до тиынов. Совпадение не гарантирует отсутствие ошибки OCR.
6. Подтверждённые позиции суммируются **по коду**, при этом сохраняется источник и все слагаемые из каждой накладной.
7. Проверяем дубли номеров накладных; формируем сводную ведомость в PDF.
8. Локальная база, редактирование любой накладной с автоматическим пересчётом ведомости.

Цены не храним как постоянные свойства товара — они могут меняться. Исходные фотографии и данные контрагентов не загружаются в этот публичный репозиторий.

## Статус

Здесь пока **только стартовый справочник и технические требования**, приложение ещё не создано.
