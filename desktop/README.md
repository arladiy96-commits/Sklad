# Склад для Windows — офлайн-PWA

Отдельная компьютерная версия находится в папке desktop/. Flutter Android-код в lib/ не затронут.

## Установка

После публикации GitHub Pages открой адрес сайта в Edge или Chrome на Windows, в меню браузера нажми «Установить приложение». Оно откроется в собственном окне, появится в Пуск и на панели задач. После первого полного открытия и загрузки кеша приложение работает без интернета.

Для локальной разработки с Node.js 22+:

    cd desktop
    npm install
    npm run dev

Проверки:

    npm test
    npm run build

Во время сборки prepare-ocr.mjs скачивает английскую и русскую модели Tesseract и собирает worker/wasm в public/ocr/. Установленное приложение распознаёт фото локально.

## Реализовано

- Накладные: вручную, фото JPG/PNG/WEBP, локальный OCR, исправление строк, обязательная галочка проверки, контроль дублей и веса кратного фасовке.
- Сводка с формулой в мешках, печать и PDF через печать браузера, выгрузка CSV для Excel.
- Товарный справочник из Android-версии и история сборок.
- Инвентаризация: локальные карточки, QR и Code128, заводские коды, приход/расход, пересчёт, движения, отчёты CSV.
- USB-сканер как клавиатура (поле сканирования + Enter). Камера в браузерах с BarcodeDetector.
- IndexedDB на устройстве, полная JSON-копия с сохранёнными фото и отдельная копия инвентаризации совместимая с Android schemaVersion=1.

## Ограничения

Android ↔ Windows автоматически не синхронизируются. OCR на ПК отличается от ML Kit: может ошибаться в кодах или количестве. Каждую строку накладной необходимо сверять по бумаге. Данные живут в профиле браузера, очистка данных сайта или удаление профиля может уничтожить базу — регулярно экспортируй JSON на другой диск. Первую установку с кешированием OCR нужно выполнить при интернете.
